Entry for the [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610?utm_source=github&utm_medium=readme&utm_campaign=u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) bounty **"One-Line Roast: The Gadget You Use Every Day"** — write a single original line of at most 200 characters that roasts a gadget or app you use every day.

## The entry

> My smartwatch throws a standing ovation every time I stand up, like fetching the TV remote is an Olympic sport.

(111 characters, one line.)

## What it does

`main.py` (Python 3.13, standard library only, deterministic — no network, clock or randomness) writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` if set, falling back to `./output/entry.txt` when `/output` is not writable). It validates the text is a single line of 1–200 characters before writing, and verifies the written file by reading it back.

## How to run

```bash
python3 main.py
cat /output/entry.txt   # or ./output/entry.txt if /output is not writable
```
